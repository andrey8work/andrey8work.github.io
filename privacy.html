Privacy Policy

Last updated: November 2, 2026

What the app accesses

With your permission, Balda Uploader uses the YouTube Data API scope youtube.force-ssl to read your channel's id and title, upload videos, set thumbnails, add captions, add videos to playlists, and read back the settings it applied.

How the data is used and stored

The app uses this access only to publish the account owner's own videos to the owner's own channels. The OAuth token is stored only on the owner's computer. No data is sent to any server other than Google's, and nothing is sold, shared or used for advertising.

Balda Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

You can revoke the app's access at any time at myaccount.google.com/permissions or security.google.com/settings/security/permissions. Revoking access makes the stored token useless.
